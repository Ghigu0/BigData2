COME ESEGUIRE IL PROGETTO

Tutti i comandi si lanciano dalla cartella principale del progetto (BigData2/).

CONTAINER MONGODB (docker)

	Creazione (solo la prima volta). Stessa versione di MongoDB della VM, i dati restano nel volume
	movies-mongo-data anche se il container viene fermato:

	docker run --name movies-mongo \
		-e MONGO_INITDB_ROOT_USERNAME=root \
		-e MONGO_INITDB_ROOT_PASSWORD=root \
		-p 27017:27017 \
		-v movies-mongo-data:/data/db \
		-d mongo:7.0.1

	Avviare / fermare il container già creato:
	docker start movies-mongo
	docker stop movies-mongo

	Cancellare tutto (container e dati), per ripartire da zero:
	docker rm -f movies-mongo
	docker volume rm movies-mongo-data

SCRIPT

	Ogni script chiede dove collegarsi: 1 = MongoDB locale (docker), 2 = VM dell'NTNU.

	Creare le collezioni (con il validator):
	python Structure/create_structure.py
	python Structure/create_structure.py --indexes      crea anche gli indici

	Popolare il database (pulisce i CSV e inserisce i dati):
	python Population_script/populate.py --small        prova veloce con ratings_small e links_small (~1 minuto)
	python Population_script/populate.py                dataset completo (~7 minuti)

	populate.py cancella e ricrea da solo le collezioni movies e ratings e alla fine crea gli indici:
	si può lanciare direttamente, anche più volte, senza passare da create_structure.py.
	Alla fine stampa il "Cleaning summary" con i conteggi della pulizia (vedi Population_script/report_pulizia.txt).

	Eseguire le query della Part 2 (database già popolato):
	python Query/queries.py                             tutte le 10 query (~1,5 minuti con il dataset completo)
	python Query/queries.py 1 7                         solo le query scelte (numeri da 1 a 10)


4. PROVARE IL DATABASE

	Aprire la shell di MongoDB dentro il container:
	docker exec -it movies-mongo mongosh -u root -p root --authenticationDatabase admin gruppo_25

	Alcuni comandi da provare nella shell:
	show collections
	db.movies.countDocuments()                          45433 con il dataset completo
	db.ratings.countDocuments()                         25974522 con il dataset completo
	db.movies.findOne({_id: 862})                       Toy Story
	db.ratings.find({user_id: 1}).limit(5)
	db.movies.getIndexes()
	db.ratings.getIndexes()
	exit
